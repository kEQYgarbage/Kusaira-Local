# Kusaira Local Anime (Kusaira)

<p align="center">
  <strong>Нативное десктопное приложение для стриминга аниме в наивысшем качестве (1080p/4K BDRip) с автоматическим PTS-скорингом релизов RuTracker и каталогом Shikimori.</strong>
</p>

---

## 🌟 Ключевые возможности

- 🚀 **Каталог Shikimori**: Доступ к полной живой базе аниме (онгоинги сезона, персональные рекомендации, золотая коллекция рейтинга, поиск по всей базе).
- 🏆 **0–100 PTS Scorer**: Интеллектуальный алгоритм оценки релизов RuTracker (1080p/4K, 10-bit HEVC, FLAC-аудио, студийные озвучки *Studio Band*, *AniLibria*, *Dream Cast* и др.).
- 🎛️ **Свободный выбор торрента**: Возможность просматривать все найденные раздачи RuTracker с их PTS-рейтингом, озвучками, сидерами и переключать релиз в один клик.
- 🔗 **Связанное (Франшиза)**: Подгрузка сиквелов, приквелов, фильмов и спин-оффов напрямую из базы Shikimori с быстрым переходом.
- 📚 **Моя библиотека**: Локальный трекер просмотров с категориями *«Смотрю»*, *«В планах»*, *«Просмотрено»* и *«Избранное»* на базе SQLite.
- ⚡ **Sequential Torrent Pre-buffering**: Мгновенный запуск воспроизведения и автоматическая предзагрузка следующей серии $N+1$ при достижении 40% текущей.
- 🎬 **Аппаратное ускорение LibVLC**: C-FFI интеграция с системным LibVLC с поддержкой аппаратного ускорения VA-API и сохранением таймкодов при смене дорожек.
- 🍪 **Zero-Login RuTracker**: Автоматический импорт куки-сессии (`bb_session`, `bb_data`) из локального профиля Firefox без ручного ввода паролей.
- ⚙️ **Гибкие настройки**: Управление приоритетами озвучек, желаемым качеством видео и параметрами ускорения.

## 🛠️ Архитектура

Приложение построено на базе высокопроизводительного нативного стека Rust:

```
src/
├── catalog/          # Shikimori API: модели, клиенты, пресеты, связи (Related)
├── scorer/           # PTS-скоринг релизов (0–100 баллов, битрейт, кодеки, озвучки)
├── torrent/          # RuTracker клиент, парсер раздач, пайплайн предзагрузки, Firefox cookies
├── player/           # LibVLC C-FFI движок воспроизведения с VA-API
├── library/          # Локальная библиотека пользователя (SQLite трекер)
├── ui/               # Десктопное окно tao + wry (WebKitGTK) со стильным темным UI
└── main.rs           # Точка входа и оркестрация жизненного цикла приложения
```

## 🚀 Быстрый запуск

### В NixOS / Linux (с окружением shell.nix)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/kEQYgarbage/Kusaira-Local.git
cd Kusaira-Local
```

2. Запустите в готовом изолированном шелле:
```bash
nix-shell --run "./bin/kusaira"
```

Или скомпилируйте релизный бинарник:
```bash
nix-shell --run "cargo build --release"
./target/release/kusaira
```

### Запуск тестов
```bash
nix-shell --run "cargo test"
```

### Самодиагностика (Headless Test)
```bash
./bin/kusaira --headless-test
```
